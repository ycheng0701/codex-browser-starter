# Development guide

## First milestone

Build one small feature end to end. Keep the scope to a single user journey, add a test for the core behavior, and document how to verify it locally.

## Initial tasks

- [ ] Initialize the Next.js and TypeScript application.
- [ ] Add the base page layout and responsive styling.
- [ ] Implement one example feature.
- [ ] Add shared types and basic error handling.
- [ ] Configure ESLint, Vitest, and GitHub Actions.
- [ ] Add the first unit test.
- [ ] Run lint, tests, and build locally.
- [ ] Open the first pull request.

## Codex task prompts

### Inspect first

> Read README.md and docs/development.md. Inspect the repository and report whether install, development, test, lint, and build commands are configured. Do not modify files.

### Implement a focused feature

> Implement the specified feature using the existing conventions. First summarize the files you will touch. Keep the change focused, add or update tests, and run lint, test, and build when finished.

### Review a change

> Review the current diff for correctness, type safety, error handling, maintainability, and test coverage. Report findings with file paths and line numbers. Do not modify files.
